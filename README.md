# Café Ruelle — Façade café template

Static site: HTML, CSS and JavaScript. three.js 0.160 loads from jsDelivr only for the motion version.
No build step on Vercel; `python3 build.py` regenerates `index.html` from `src/`.

    index.html      the site (generated)
    src/head.html   title, fonts, CSS (torn-paper edges are generated by build.py)
    src/body.html   markup, the SITE content object, the scroll engine
    src/cup.js      the three.js to-go cup (profile measured from media/cup.png)
    media/          video, clean plate, cup PNG, logo variants, images

## How the hero works
1. `media/pour-1080.mp4` / `-720.mp4` (the Kling clip, every frame a keyframe) is scrubbed by scroll.
2. On the last frame, `media/cup.png` appears exactly over the cup (it sits at x 1097, y 384,
   335 × 426 px in the 1920 × 1080 frame), and `media/plate.webp`, the same frame with the cup and
   steam removed, swaps in under it.
3. As the visitor scrolls on, the PNG cross-fades into the three.js cup, which spins twice, gets the
   logo, and lands facing front in the slot next to the "Our ritual" statement. Visitors can drag it.
4. With reduced motion, the hero is a still and the slot shows `media/cup-logo.png`.

Content (menu, prices, beans, hours, address) is in the `SITE` object at the top of the script;
in Façade each key maps to a Payload field.

## Re-encoding a new clip
    ffmpeg -i clip.mp4 -an -vf scale=1920:-2 -c:v libx264 -g 1 -crf 22 -pix_fmt yuv420p -movflags +faststart media/pour-1080.mp4
    ffmpeg -i clip.mp4 -an -vf scale=1280:-2 -c:v libx264 -g 1 -crf 25 -pix_fmt yuv420p -movflags +faststart media/pour-720.mp4
A new clip also needs a new clean plate and new cup coordinates (VID.cup in src/body.html).

## Deploy
    python3 build.py
    npx vercel --prod
